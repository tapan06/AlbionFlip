# Albion Flip — by Memory Shards

**Albion Flip** — веб-сканер прибыли и радар маршрутов для рынка **Albion Online**:
- **Сделки**: Чёрный рынок, межгородские перевозки и флип в одном городе с учётом налогов, сборов, веса и спроса за 7 дней.
- **Зачарование**: расчёт выгодного апгрейда снаряжения рунами, душами и реликвиями.
- **Крафт**: калькулятор себестоимости снаряжения, еды и зелий с возвратом ресурсов.
- **Карта и сводка гангов**:
  - Оригинальный граф локаций Albion Online с фоном континентов и биомов, поиском любой зоны по названию.
  - Умный расчёт только **реально отличающихся маршрутов** (без дубликатов с одними и теми же красными зонами): Короткий, Безопасный (меньше красных зон) и Обходной (через другой вход).
  - Индикатор **Прайм-тайма серверов** (Европа, Америка, Азия) и **автопроверка Killboard каждые 5–10 минут**: ищет убийства пачками, в сетах гангеров и атаки на перевозчиков, показывая предупреждение и подробную сводку смерти.
- **Рюкзак и корзина**: сбор груза под конкретного маунта, сумку и пирог с экспортом/импортом набора снаряжения напрямую в игру.

---

## 💻 Запуск локально на Windows (чтобы работала Сводка гангов)

Если просто открыть `index.html` двойным кликом (`file://`), браузер блокирует запросы к официальному Killboard из-за политики безопасности **CORS**.

Для полноценной работы запускай файл **`Запустить Albion Flip.bat`** из папки проекта:
- Он запускает встроенный локальный сервер (`server.ps1` на PowerShell, ничего устанавливать не нужно) с рабочим прокси `/api/kills` и сам открывает сайт в браузере.

## 🚀 Как сделать сайт открытым для всех по ссылке

### Вариант 1: Vercel или Netlify из GitHub-репозитория (рекомендуется — всё работает из коробки)
1. Загрузи все файлы этой папки в публичный репозиторий на [GitHub](https://github.com/new), например `AlbionFlip`.
2. Подключи этот репозиторий на [vercel.com](https://vercel.com) или [netlify.com](https://app.netlify.com) (бесплатно, в 2 клика).
3. В проекте уже встроены серверные функции **`api/kills.js`** (для Vercel) и **`netlify/functions/kills.js` + `netlify.toml`** (для Netlify) — поэтому и рынок, и **Сводка гангов Killboard** будут стабильно работать у всех пользователей по ссылке.

### Вариант 2: GitHub Pages
1. В репозитории открой **Settings → Pages → Build and deployment → Source** и выбери **GitHub Actions** (файл `.github/workflows/deploy.yml` уже настроен).
2. Сайт откроется по ссылке `https://<ТВОЙ_ЛОГИН>.github.io/AlbionFlip/`.
3. Чтобы на статическом GitHub Pages стабильно работала «Сводка гангов», можно за 1 минуту создать бесплатный **Cloudflare Worker** (вставь туда код из файла **`cloudflare-worker.js`**) и указать его адрес в кнопке **«⚙️ Свой прокси»** в карточке сводки.
